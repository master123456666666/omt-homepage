プライバシーポリシー

このページは、テスト版（TestFlight で配布している版）の FITTY を対象としています。正式公開の前に内容を見直し、変更する場合はこのページでお知らせします。

株式会社OverTure（以下「当社」）は、ファッションアプリ「FITTY」（以下「本アプリ」）で取り扱う情報について、次のとおり定めます。

1. 取得する情報

本アプリは、名前・メールアドレス・電話番号などの登録を求めません。はじめて起動したときに、端末ごとのランダムな ID（以下「匿名 ID」）を発行し、次の情報をその匿名 ID に結びつけて保存します。

  • 最初に選んでいただく内容：見たい服の区分（メンズ・ウィメンズ・両方）、気になる系統、自由に書いた系統
  • 任意でお答えいただく内容：生まれ年、お住まいの都道府県
  • 本アプリの使い方：表示した服、LIKE・SKIP・SAVE、詳細を開いた服、公式 EC サイトへ移動した服と、その日時
  • 上の情報から計算した好みの傾向（系統・色・形など）と、おすすめの結果
  • 利用日時など、サービスの運営に必要な記録

本アプリは、位置情報（GPS）、連絡先、写真、カメラ、マイク、広告 ID を取得しません。広告や解析のための外部のツールも組み込んでいません。

2. 利用目的

  • あなたの好みに合わせて服を並べ、おすすめ（FOR YOU）を作るため
  • 本アプリの不具合の調査と、改善のため
  • 利用状況を、個人が分からない形に集計して分析するため
  • 不正な利用を防ぐため

3. 第三者への提供

法令に基づく場合を除き、取得した情報を第三者に提供しません。

「公式ECで見る」を押すと、そのお店のサイトが開きます。お店のサイトで入力した情報は、そのお店の方針に従って扱われます。本アプリから匿名 ID などをお店に渡すことはありません。

4. 外部サービスの利用

情報の保存と処理に、Google Cloud（日本国内のリージョン）を利用します。

5. 保存期間と削除

情報は、サービスの提供に必要な間、保存します。

ご自身の情報の削除は、本アプリの「PROFILE > データを削除」（順次提供します）、または下のお問い合わせ先から依頼できます。削除した後も、障害対策のためのバックアップと運用の記録は、一定期間が過ぎて自動で消えるまで残ることがあります。

アプリを端末から削除しただけでは、当社が保存している情報は消えません。

6. 安全管理

通信は暗号化し、情報へのアクセスは必要な担当者に限ります。

7. 未成年の方

未成年の方は、保護者の同意を得てからご利用ください。
